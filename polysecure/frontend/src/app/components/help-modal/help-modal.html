Como usar o PolySecure

@if (activeTab() === 'standard') {

O modo SQL Padrão envia a query diretamente ao PostgreSQL. Use o prefixo store.tabela para indicar em qual store a tabela está.

Selecionar dados

-- Todos os registros de uma tabela
SELECT * FROM pg.users;

-- Com projeção de colunas
SELECT id, name FROM pg.users;

-- Com filtro WHERE
SELECT id, name FROM pg.users WHERE active = true;

-- Com alias de tabela
SELECT u.id, u.name
FROM pg.users u
WHERE u.id = 1;

Convenções

  • O prefixo (pg, mg, neo) é o nome da store registrada.
  • No modo padrão, apenas uma store por query — sem JOIN cross-store.
  • Para queries cross-store, use o modo SQL-Poly.
} @if (activeTab() === 'poly') {

O modo SQL-Poly é a linguagem nativa do PolySecure. Suporta JOIN entre stores diferentes, DDL e DML cross-store.

SELECT cross-store

-- JOIN entre PostgreSQL e MongoDB
SELECT u.name, p.bio
FROM pg.users u
JOIN mg.profiles p ON u.id = p.user_id
WHERE u.active = true;

DDL — Criar / Remover tabela

-- Criar tabela distribuída em múltiplas stores
CREATE POLYSTORE TABLE orders (
  id       INT      STORE pg PRIMARY KEY,
  detalhes DOCUMENT STORE mg,
  grafo    GRAPH    STORE neo
);

-- Remover tabela
DROP POLYSTORE TABLE orders;

DML — Inserir, Atualizar, Deletar

-- INSERT em múltiplas stores simultaneamente
INSERT INTO POLYSTORE orders
  pg (id, total)    VALUES (1, 150.0)
  mg (id, detalhes) VALUES (1, 'descricao do produto');

-- UPDATE cross-store (atualiza pg e mg de uma vez)
UPDATE POLYSTORE orders
  SET pg.total = 199.9,
      mg.detalhes = 'atualizado'
  WHERE id = 1;

-- DELETE cross-store
DELETE FROM POLYSTORE orders WHERE id = 1;

Tipos de coluna suportados

  • INT, TEXT, FLOAT — colunas relacionais (PostgreSQL)
  • DOCUMENT — documento JSON (MongoDB)
  • GRAPH — nó ou relação (Neo4j)

Stores podem ser adicionadas diretamente pelo painel lateral esquerdo: clique no botão + ao lado de "Stores", preencha o formulário e clique em "Adicionar". Para remover, passe o mouse sobre a store e clique em ×.

Também é possível registrar via API REST usando um cliente HTTP (Postman, curl, Insomnia).

Endpoint de registro

POST http://localhost:8080/stores
Authorization: Bearer <seu-token>
Content-Type: application/json
